# 2026-10-24 新执行器 USB 实验

历史实验记录：本页描述专用实验入口；后续正式 `pizza-maint` 物理入口的开放与验收见[生产入口记录](hardware-production-2026-10-24.md)。

用户指定插入的 U 盘后，在固定序列号 `FC046CE92485C`（`VendorC ProductCode`）上重新运行硬件实验。使用当前工作树、Zig 0.17.0、Safe 模式；生产物理写盘门禁保持关闭，实验设备显式授权可写。

## 范围与前置核对

沿用上次实验的分区 1：起始扇区 20,000,768，长度 52,674,166,784 字节，逻辑扇区 512 字节。没有修改分区表和另外两个分区。这个容量来自已有分区，不是新建的大镜像；默认镜像验收已缩为 1000 MiB 数据区。

预检确认分区 1 未挂载，为空 FAT32。原用户文件仍按[上次实验](hardware-experiment-2026-10-23.md)保存：电脑和分区 3 各一份，共 12 个文件、7,818,790 字节，两份清单逐文件 SHA-256 全部相符。分区 3 临时只读挂载以核对备份。每次原生修改再次核对备份、序列号、分区表、几何，并持有分区 1 的 `O_EXCL` 句柄；独立读回使用 `O_DIRECT`。

硬件入口已迁到生产语义接口、共用规划器、不可变 v7 物理程序和 v5 恢复协议。按用户确认，产品尚未上线，不提供旧协议兼容；生产和硬件入口均直接调用新恢复器。

## 场景与结果

使用固定 4 MiB 随机测试文件 `PIZZA.BIN`，将它放到分区内偏移 52,665,711,616 字节，并清零旧数据副本，确保缩容确实需要搬移尾部数据。

| 场景                                                     | 结果                                       |
| -------------------------------------------------------- | ------------------------------------------ |
| 原盘查询、空卷检查、两份备份、磁盘边界和分区 2 基线      | 通过                                       |
| 缩到 40 GiB，全部步骤刷盘后、提交前中断                  | 新进程回滚，独立基线和文件核对通过         |
| 第一次目标写入仅刷盘 257 字节，随后 SIGKILL              | 已在真实介质上触发                         |
| 恢复完成第一个目标步骤后再次中断                         | 新进程继续恢复通过                         |
| 再次恢复相同日志                                         | 返回 `rolled_back`，独立基线和文件核对通过 |
| 正常缩到 42,949,672,960 字节（40 GiB）                   | 455 步提交，独立检查及文件核对通过         |
| 扩回 52,674,166,784 字节                                 | 199 步提交，独立检查及文件核对通过         |
| 重新打开成功扩容的恢复记录                               | 返回 `committed`                           |
| 清理夹具，原生创建原容量空 FAT32，再次检查及打开提交记录 | 197 步提交，独立空卷检查通过               |

两次中断回滚均由实验监督器在修改前独立保存的 FAT 基线检查：2 个连续有效范围，共 17,103,872 字节，覆盖所有格式元数据和当时已分配的簇。恢复后以 `O_DIRECT` 逐字节比较，全部一致。基线仅是独立判据，不参与原生恢复；执行器只使用自身持久化的程序、状态、undo 快照和暂存文件。

文件 SHA-256 始终为 `2f123cf664411a17345ffc8e055db6652774fd355f66ff6fdcbb3de16c73156d`。独立 `fsck.fat -n`、mcopy 和直接 FAT 链读取都通过。mtools 仍输出上次已有的几何提示，但返回成功；本次不验证引导能力。

成功缩扩容的受控分配峰值分别为 183,283,712 和 293,572,608 字节；观测到的最低可用内存超过 16 GB，高于约 3.34 GB 安全余量，没有余量违例。这是采样和受控分配观测。
